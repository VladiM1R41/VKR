## 9. Мониторинг здоровья

Что может сломаться:
- RSS перестал отвечать
- изменился формат item
- перестал извлекаться full text
- резко упала длина `content`
- исчезли `author` / `category`

Минимальные health-check сигналы:
- RSS отвечает `200`
- есть записи
- даты парсятся
- текст извлекается
- `avg_content_length` не просел

Нормальные значения:
- `articles_last_24h = ...`
- `avg_content_length = ...`
- `error_budget / tolerable failure rate = ...`
